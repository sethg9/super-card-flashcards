# Super Card Flashcards

An offline Windows flashcard app for studying at your own pace—with math, images, and no daily limits or due dates. Made to be a perfect offline Quizlet Alternative.

**[Download for Windows](https://github.com/sethg9/super-card-flashcards/releases/latest)** · **[User guide and tutorials](https://github.com/sethg9/super-card-flashcards/wiki)**

- Study freely with Flashcards, or use Learn to review only cards you are still learning.
- Create decks, search cards, and shuffle.
- Write math with offline MathJax and add images to either side.
- Choose Light, accent-tinted Dark, or OLED Black, with custom accents and backgrounds.
- Import CSV/TSV, export cards with media, and back up your library.
- Use keyboard controls and optional animated flips with reduced-motion support.

## Choose your download

- **Installer (`SuperCard-Setup-…-x64.exe`)** — recommended for normal installation and Start-menu shortcuts.
- **Portable (`SuperCard-Portable-…-x64.exe`)** — double-click to run without an installation wizard.

Both are for Windows x64 and save data in `%APPDATA%\SuperCard`. The portable executable **does not carry your library**; use backups to move cards between computers.

The current executables are **unsigned**. Windows may show SmartScreen or unknown-publisher prompts.

See the **[Wiki](https://github.com/sethg9/super-card-flashcards/wiki)** for installation, keyboard controls, CSV examples and an LLM prompt, math, images, appearance, and backups.
