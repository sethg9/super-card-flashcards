# SuperCard user guide

Offline flashcards with math, images, and study at your own pace.

**[Download the latest Windows version](https://github.com/sethg9/super-card-flashcards/releases/latest)**

Start with [Installation and getting started](https://github.com/sethg9/super-card-flashcards/wiki/Installation-and-getting-started), then choose a guide:

- [Creating and studying cards](https://github.com/sethg9/super-card-flashcards/wiki/Creating-and-studying-cards) — decks, editing, and keyboard controls.
- [CSV import and export](https://github.com/sethg9/super-card-flashcards/wiki/CSV-import-and-export) — compatible files, media folders, examples, and a copyable LLM prompt.
- [MathJax and images](https://github.com/sethg9/super-card-flashcards/wiki/MathJax-and-images) — math syntax and supported image files.
- [Themes and appearance](https://github.com/sethg9/super-card-flashcards/wiki/Themes-and-appearance) — Dark, OLED, accents, backgrounds, and animations.
- [Backups and storage](https://github.com/sethg9/super-card-flashcards/wiki/Backups-and-storage) — protect your library and move it between computers.
